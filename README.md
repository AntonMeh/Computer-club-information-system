# Клубна система (Cyberion)

Повнофункціональна інформаційна система мережі комп'ютерних клубів: керування залом у реальному часі, облік клієнтів і бонусів, тарифікація сеансів, приймання оплат із друком 80-мм чека, облік операційних витрат, організація кіберспортивних турнірів, управління персоналом та аналітична звітність.

**Технологічний стек:**
- **База даних:** PostgreSQL 16 (або SQLite для ізольованих автотестів)
- **Бекенд:** Python 3.11+ · FastAPI · SQLAlchemy 2.0 · Alembic · PyJWT / Passlib (bcrypt)
- **Фронтенд:** React 18 · Vite 5 · React Router 6 · Lucide Icons · власна дизайн-система без важких UI-фреймворків

## Швидкий старт (Windows PowerShell)

Потрібні встановлені: **Python 3.11+**, **Node.js 18+** та **PostgreSQL** (локально або через Docker).

### Варіант А — Автоматичний запуск одним скриптом

У кореневій папці проєкту виконайте:

```powershell
.\start.ps1
```

Скрипт автоматично перевірить підключення, застосує міграції, за потреби створить демо-користувачів і відкриє два вікна PowerShell (бекенд на `http://127.0.0.1:8000` та фронтенд на `http://127.0.0.1:5173`).

---

### Варіант Б — Покроковий ручний запуск у Windows PowerShell

#### 1. База даних PostgreSQL (через Docker)

```powershell
Copy-Item .env.example .env -ErrorAction SilentlyContinue
docker compose up -d db
```

*(Якщо використовується локальний PostgreSQL, укажіть параметри підключення у файлі `backend/.env`).*

#### 2. Налаштування та запуск бекенду (Вікно PowerShell № 1)

```powershell
cd "backend"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
Copy-Item .env.example .env -ErrorAction SilentlyContinue

# Згенерувати криптографічно стійкий SECRET_KEY (мінімум 32 символи)
$key = python -c "import secrets; print(secrets.token_urlsafe(48))"
(Get-Content .env) -replace '^SECRET_KEY=.*', "SECRET_KEY=$key" | Set-Content .env

# Застосувати міграції та наповнити БД демо-даними
python -m alembic upgrade head
python -m app.seed --reset

# Запустити сервер FastAPI
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

- **API:** `http://127.0.0.1:8000`
- **Інтерактивна документація Swagger:** `http://127.0.0.1:8000/docs`

#### 3. Налаштування та запуск фронтенду (Вікно PowerShell № 2)

```powershell
cd "frontend"
Copy-Item .env.example .env -ErrorAction SilentlyContinue
npm install
npm run dev
```

- **Веб-інтерфейс:** `http://localhost:5173`

## Реалізовані розділи інтерфейсу

1. **Вхід (`/login`) та Профіль (`/profile`):** JWT-авторизація, захист від перебору пароля (rate limit), примусова зміна тимчасового пароля, налаштування щільності таблиць.
2. **Огляд (`/`):** KPI-картки з порівнянням до вчора/минулого місяця, картки «Поточна зміна» та «Каса за вчора / Z-звіти», 14-денний графік виручки, міні-сітка місць у реальному часі, найближчі турніри, останні оплати та блок попереджень «Увага».
3. **Зал (`/hall`):** Картки робочих місць із живими таймерами, індикацією вартості, інформаційним вікном характеристик ПК та ігрової периферії (`Standard`, `VIP`, `PlayStation 5`), перевіркою відкритої зміни, швидким стартом і завершенням сеансів за 3 кліки.
4. **Зміна (`/shift`):** Відкриття зміни з фіксацією розмінної готівки, поточний X-звіт, формула грошової шухляди, службові операції (`внесення`, `вилучення` з автостворенням витрати, `інкасація`), 3-кроковий майстер закриття зміни з калькулятором купюр та примусове закриття директором.
5. **Каса і Z-звіти (`/cash`, `/cash/z/:id`):** Реєстр змін та Z-звітів, денна каса по клубах із розгортанням змін, журнал службових операцій, друкована форма Z-звіту (A4 та 80 мм) із підтвердженням бухгалтером.
6. **Сеанси (`/sessions`):** Журнал активних, завершених і скасованих сеансів із фільтрами за періодом і статусом.
7. **Оплати (`/payments`):** Незмінний фінансовий журнал із прив'язкою до зміни (`Z-номер`), підсумками за способами оплати (`готівка`, `картка`, `бонуси`), експортом CSV та друком чека 80 мм.
8. **Клієнти (`/clients`, `/clients/:id`):** База гравців із пошуком, карткою клієнта, історією сеансів/оплат/турнірів і ручним коригуванням бонусного балансу.
9. **Тарифи (`/tariffs`):** Триколонкове подання тарифів за типами місць (`Standard`, `VIP`, `PlayStation`).
10. **Робочі місця (`/workstations`):** Облік місць клубу, групове створення діапазонів номерів (`POST /workstations/bulk`), перемикання статусу ремонту.
11. **Витрати (`/expenses`):** Облік витрат за 5 категоріями з діаграмою структури витрат і CSV-експортом.
12. **Турніри (`/tournaments`, `/tournaments/:id`):** Картки турнірів, реєстрація учасників, призначення призових місць (1, 2, 3) і подіум переможців.
13. **Звіти (`/reports`):** 5 аналітичних вкладок (**Фінанси P&L**, **Завантаженість з тепловою картою 7×24**, **Тарифи і місця**, **Клієнти**, **Турніри**), експорт у CSV та друк.
14. **Співробітники (`/staff`):** Табличний реєстр та інтерактивна деревоподібна оргструктура клубу з підсвічуванням вакантних посад.
15. **Клуби (`/clubs`) та Користувачі (`/users`):** Адміністрування філій мережі, облікових записів і скидання паролів із видачею тимчасового коду.

## Перевірка якості (Тести та Production-збірка)

### Автотести бекенду (`pytest`)

Тести автоматично використовують ізольовану SQLite-базу в пам'яті та перевіряють усі 14 бізнес-правил, матрицю прав 6 ролей, транзакційність оплат і бонусів, а також точність розрахунків у звітах:

```powershell
cd "backend"
.\.venv\Scripts\python.exe -m pytest -q
```

### Перевірка збірки фронтенду (`vite build`)

```powershell
cd "frontend"
npm run build
```
